# Credits

## Audio

All audio in Robo Arena (sound effects, ambiences, announcer stingers, jingles and every music
track) is original and procedurally synthesized at runtime in the browser with the Web Audio API.
That means oscillators, FM, filtered noise, waveshaping and a procedurally generated
convolution-reverb impulse response. The music is composed in code and played by a built-in step
sequencer.

The game ships no audio files, samples or third-party audio assets. The code lives in `src/audio/`.
