## Model translation priorities

1. Establish the silhouette and negative space first: swept shoulders, narrow waist, exposed joints, long split shin shells.
2. Use compound ridged armor geometry with actual thickness; surface markings cannot rescue a flat silhouette.
3. Keep four distinct class shapes and preserve all interchangeable leg/weapon models.
4. Validate front, back, run and fire poses plus the gameplay camera. Reference-level microdetail is an artistic target, not a rendering requirement.
